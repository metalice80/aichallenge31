# Проверка обновления документации по пользовательскому diff

19 октября 2026. Исходный запрос сохранён без уточнения путей и поведения в `../run_docs_demo.py`. Все модельные повторы используют настоящие Qwen3 8B, BGE-M3 и MCP/stdio. Публикация выключена, `apply=False`. У Outline сохранены пользовательская правка `server/main.ts`, ветка, HEAD, Git-status и хеши 2598 файлов. Полные журналы находятся в `.task-runs/docs-demo-fix/<run_id>/`.

## Исходный сбой

`f3d54d4183aa441889eaeca927a557cc`: diff показал включение HTTP middleware в development, но модель не прочитала изменённый `server/main.ts` или документацию. Она прочитала `server/env.ts` и `server/utils/environment.ts`, затем трижды пыталась добавить комментарии в TypeScript. Allowlist отклонил эти предложения. Это провал выполнения задачи, а не ошибка пользователя, timeout или недоступность Ollama.

## Исправления

- Сведения о diff сохраняются в manifest. Контроллер учитывает прочитанные диапазоны по строкам и версии; прежде чем продолжить поиск, нужно прочитать изменённые hunks. MCP самостоятельно запрещает предложение/завершение до этого чтения.
- Сводка истории сохраняет цель, источники, непрочитанные диапазоны и ограниченный фрагмент diff. Текущий этап передаётся модели отдельно от результатов файловых инструментов и сохраняется в `events.jsonl` как `controller`.
- При изменении кода требуется второй прочитанный файл кода, если такой файл доступен. Модель получает инструкции найти определение условия/конфигурации или тест. Подсчёт файлов сам по себе не устанавливает их смысловую релевантность — один из повторов ниже это демонстрирует.
- Разрешённые Markdown-пути сообщаются модели. Схема предложения отвергает пути исходников, MCP сохраняет независимый allowlist. Недоступные на этапе инструменты нельзя вызвать в обход показанной модели схемы.
- Преждевременное текстовое завершение возвращает подсказку о недостающем шаге. Пустой ответ также учитывается в лимите ошибок.
