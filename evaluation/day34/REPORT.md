## Автоматические проверки

100 тестов: прежние 49 регрессий и 51 проверка файлового режима. Полный набор: 100 passed за 51,93 с; после последней правки доступности завершения затронутые 13 тестов цикла прошли за 8,19 с. Проверяются разные имена/пути fixture, многошаговые MCP-вызовы, overlay, dry-run и явное применение, источники и хеши, запрет symlink/выхода за корень/секретов, Markdown и diff без конечного перевода строки, staged/unstaged/untracked, ограничение прав `/help` и PR review, ошибки/таймауты/циклы, сбои между файлами и восстановление без потери чужих правок. Replay CLI проверяется с запретом даже конструировать клиент Ollama.

В `outline-initial/outline-result.json` сохранён первый частичный dry-run: прежний скрытый бюджет буквального поиска обрывал сканирование до `shared`, повторные совпадения могли заполнять выдачу одним файлом. Исправлены независимый бюджет 50 МБ и выдача по разным файлам; повторный dry-run прошёл.

Qwen3 8B не гарантирует релевантность и одинаковый результат повторной генерации. В частности, ранее сгенерированные отчёты могут отвлекать её от документации. Демонстрация A/B теперь использует независимые временные проекты; смешанный корпус из ранних попыток не объявлен исправленным. Для практической задачи с узким назначением можно сузить `task_write_include`, например оставить только `README.md` и `docs/**/*.md`; модель всё равно должна пройти проверку результата человеком.

## Воспроизведение

```bash
.venv/bin/python -m pytest -q
.venv/bin/python evaluation/day34/run_real.py
.venv/bin/python evaluation/day34/run_outline.py
# Повторная проверка уже применённой документации последнего fixture:
.venv/bin/python evaluation/day34/repeat_saved.py
```

`run_real.py` сам создаёт два временных проекта и проверяет смысл обновления (10/50 → 25/100), сохранность пользовательской заметки и исходников. В `results.json` записываются конфигурации обоих проектов, run_id, успешные read_file и настоящая последовательность инструментов. Для CLI replay Ollama URL заменяется на недоступный `http://127.0.0.1:9`. Скрипт завершается ненулевым кодом при невыполненных критериях, даже если модель заявила успех.

Полные пакеты находятся в `.task-runs/real-day34/<run_id>/` и `.task-runs/outline-day34/<run_id>/`. Они и сырые `.log` исключены из Git. JSON здесь — компактные результаты измерений; для воспроизведения на другом компьютере запускайте скрипты, абсолютные временные пути этого компьютера переносить не нужно. `help.txt` — настоящий ответ `/help`; `outline-result.json` содержит сравнение read-only снимков Outline.

## Ограничения

Формальные проверки источников/путей/хешей не доказывают каждое утверждение в тексте. Минимум три чтения не означает полноту анализа. RAG ограничен 40 файлами на выбранную моделью область, буквальный поиск и чтение также ограничены; динамические вызовы могут быть пропущены. При необходимости сужайте запрос/область, проверяйте preview и журнал. PR-лимит 1000 сохранён независимо.

Применение нескольких файлов — журналируемая последовательность атомарных операций над отдельными файлами. Отключение питания физически не испытывалось; тесты инъецируют сбой и незавершённый журнал. Во время короткой фазы записи не редактируйте те же файлы сторонним редактором. Внешний GitHub PR/workflow в этой задаче не запускался и не публиковался; его регрессия проверена автоматическими тестами. Установленный runner runtime не обновлялся.
