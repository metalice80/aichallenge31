## Исправления по результатам проверок

- При первом прогоне обнаружено избыточное перечисление сведений и неподтверждённые рассуждения о содержимом файлов из MCP-списка. Промпт уточнён: ответ только по вопросу, факты с ID, при отсутствии данных — один короткий абзац. Общий `/help` спрашивает краткое назначение проекта.

- После исправлений повторены затронутые тесты и полный реальный прогон. Первая версия результатов сохранена отдельно: [initial-results.json](initial-results.json); она не является финальным показателем качества.
